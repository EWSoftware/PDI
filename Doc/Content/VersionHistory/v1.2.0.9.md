Version 1.2.0.9 was released on April, 17th, 2006.



## Changes in This Release

Added static `VCalendar.TimeZoneTimeToUtc` and `VCalendar.UtcToTimeZoneTime`
methods to convert time zone date/times to/from universal time.  Fixed `VCalendar.TimeZoneToTimeZone`
so that it correctly converts times between time zones near the standard time/daylight saving time shift.
