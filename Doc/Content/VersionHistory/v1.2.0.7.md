Version 1.2.0.7 was released on December 29th, 2005.



## Changes in This Release

- Modified the behavior of the `Clone` method in `UniqueIdProperty`
so that it always keeps the same ID as the source object.  If a new ID is required, it must be generated or
assigned after cloning it.
- Adjusted the parser's handling of line folds so that it handles ill-formed folds at the end of
a block of text with no data on the last line.
- Fixed a problem with property character set encoding in vCard 2.1 files.
