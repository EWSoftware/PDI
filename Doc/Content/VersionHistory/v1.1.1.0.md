Version 1.1.1.0 was released on April 2nd, 2005.



## Changes in This Release

- Modified the `Recurrence` class's `Parse` method
so that it does not reset the `StartDateTime` property.
- Added code to the web server `RecurrencePattern` control to reset the
focused control after post backs to reduce the need to scroll down the page as often.
