Version 1.2.0.4 was released on September 6th, 2005.



## Changes in This Release

- Fixed a bug in the property serialization code that occurred when serializing Unicode
characters in conjunction with quoted-printable encoding and a character set specification.
- Modified the time zone parsing code to accept the optional seconds portion and modified the
time zone offset properties to include the seconds if specified.
